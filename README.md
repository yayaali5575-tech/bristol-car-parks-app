# Bristol Car Parks App

## Overview
This project is a simple web application that displays Bristol car park data.

The application allows users to click a button to load and view a list of car parks.

## Features
- Displays Bristol car parks
- Button to load data
- Simple and easy-to-use interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the website
2. Click the "Load Car Parks" button
3. View the list of car parks displayed

## Live Website
https://yayaaali5575-tech.github.io/bristol-car-parks-app/

## Project Structure
- index.html – main webpage
- script.js – handles button and data display
- style.css – styling for the page
