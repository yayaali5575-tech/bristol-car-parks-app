# Bristol Car Parks App

## Overview
This project is a simple web application developed as part of my coursework portfolio at UWE Bristol.

The application displays a list of Bristol car parks when the user clicks a button. It uses basic HTML, CSS, and JavaScript, with hardcoded data to demonstrate functionality.

## Features
- Displays Bristol car parks
- Button to load car park data
- Simple and easy-to-use interface
- Runs in the browser with no setup required

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages

## How to Use
1. Open the website  
2. Click the **"Load Car Parks"** button  
3. View the list of car parks displayed
